## TowRecover (towed-vehicle auction analytics) — KILL (orchestrator, strict novelty)
Verifier: CONDITIONAL PASS ("real niche gap, novelty overstated"). Orchestrator ruling: FAIL high-confidence novelty — IAA Vehicle Value® (CV damage matrix + ML pricing on auction outcomes) and ACV MAX provide the same service for vehicles in sibling auction channels; Autura owns impound distribution and is "one product decision away." Same pattern as iter1 ScanBoost kill (thin channel differentiation ≠ category). Also D requires building the corpus via multi-platform scraping with untested ToS legality.
Learning: mechanism-sibling ideas fail when the mechanism is productized for the SAME asset class anywhere; they pass only when the asset class itself is untouched (storage units yes, vehicles no).
